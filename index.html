MySolo

A private, single-user productivity integration operated by the owner of this GitHub account. It is not a public sign-up service and is not affiliated with or endorsed by Google.

Purpose

MySolo uses owner-authorized Google Drive, Google Docs and Google Sheets API access to organize personal files, back up selected documents, and read or update documents and spreadsheets when the owner requests it. AI-assisted processing may be used for tasks the owner initiates.

Access and control

Google access is granted through OAuth. The owner controls which requests are made and can revoke access at any time in Google Account settings. This public website contains only app information and policies; it does not collect Google credentials or display private documents.

Read the privacy policy and terms before authorizing access.
