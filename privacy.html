Privacy Policy

MySolo is a personal, single-user integration. This policy describes its intended use of Google user data.

Data accessed and purpose

With the owner's OAuth authorization, MySolo can access Google Drive file metadata and contents, and read or modify Google Docs and Sheets. Access is used to fulfill owner-directed productivity tasks, such as document organization, backups, summaries and spreadsheet updates. Broad API permissions do not authorize unrelated actions.

Processing and sharing

Google data is processed on the owner's computer and stored in the owner's Google account or local task files as needed. Relevant content may be sent to the configured AI service to fulfill an owner-initiated request. Such processing is subject to that service's terms and privacy policy. MySolo does not sell Google user data, use it for advertising, or publish private documents on this website. MySolo does not use Google user data to train generalized AI or machine-learning models.

Storage, retention and security

OAuth credentials remain outside this public repository and website. Local caches, task outputs and backed-up documents may remain until the owner deletes them. The owner should retain only necessary data and protect the computer and accounts. No security system can guarantee absolute protection.

Revocation and deletion

The owner may revoke MySolo access through the Google Account third-party connections page, remove local OAuth credentials, and delete local caches or stored documents. Revocation stops future API access but does not itself delete existing copies or backups.

Google API policy

MySolo's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Website and contact

This static site does not intentionally collect form submissions or add analytics or advertising scripts. GitHub operates the hosting infrastructure under its own privacy statement. Contact the operator through this repository's issues; do not post credentials or private documents publicly.
